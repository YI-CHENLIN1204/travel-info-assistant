# 旅客資訊顯示政策

## 2026-10-24 調整

- 警報頁隱藏水庫／放流、降雨／豪雨／暴雨、強風與道路封閉類公告。
- 保留颱風、熱帶氣旋、地震、海嘯、火山、撤離／疏散，以及停駛、停航、取消、交通中斷等重大事件；其他類別需達 severe/emergency。
- 同發布機關、類別及地區只顯示最新一筆；此為旅客閱讀篩選，不代表被隱藏事件無風險，完整資訊仍查官方來源。
- 天氣為 MET Norway 模型預報，非即時觀測，顯示發布與適用時間。快取改存原始預報，每次回應重新對應目前時間，避免持續顯示數小時前的第一個預報點。
- 機場搜尋補上常用繁體中文城市／機場別名與顯示名稱，台北可同時找到桃園與松山；未收錄的全球機場仍可用英文或代碼查詢。
- 保留原有 airports.min.json 未提交修改，本次不修改也不提交該檔。
- 前端集中執行測試、型別檢查與 build；後端因環境無 .NET SDK，新增測試仍待執行。
